ClickMore 0.1.2 improves Settings editing and makes Accessibility setup easier.

### Changes

- Type the delay between clicks directly; values stay within 1–250 ms. The input, unit, and stepper fit on one row.
- Return applies an edit, Escape cancels it, and outside clicks finish editing. Closing Settings or quitting applies pending edits; reopening Settings leaves the number field unfocused.
- Add standard Paste, Cut, Undo/Redo, and Command-W shortcuts, with native Tab navigation and screen-reader labels.
- Highlight the Mouse access section with three outline pulses when access is needed. Reduce Motion uses a steady highlight.
- Add a floating drag-to-Accessibility helper using PermissionFlow 2.11.3, including its upstream sizing and window-tracking fixes. The helper closes after access is granted.
- Add a static product website with an interactive four-button demo and installation links.
- Include the permission helper’s localized resources and MIT license in development and release bundles.

### Install

- **Homebrew:** `brew install --cask helgesverre/tap/clickmore` (or `brew upgrade --cask helgesverre/tap/clickmore` for an existing Homebrew installation).
- **PKG:** download `ClickMore-0.1.2-universal.pkg` and follow Installer.
- **ZIP:** extract `ClickMore-0.1.2-universal.zip` and move ClickMore.app to Applications.

Supports macOS 14 or later on Apple Silicon and Intel. The app and installer are Developer ID signed, notarized by Apple, and stapled. Use **Open Accessibility Settings…** in ClickMore to show the drag helper, then add ClickMore to the Accessibility list and enable its switch.

`SHA256SUMS` verifies both downloads. `BUILD_INFO` identifies the exact release source commit.
