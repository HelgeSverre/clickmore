ClickMore 0.1.3 fixes click cancellation when removing spots or quitting the app.

### Fixes

- Removing a click spot now cancels a running batch, preventing queued clicks at the removed target. Removing a spot that no longer exists leaves the batch unchanged.
- Cancelling a sequence after its press delay completes no longer sends a duplicate mouse-up if shutdown has already released the button.

### Maintenance

- Keep layout and preference mutations inside the app controller so edits consistently follow validation, persistence, and cancellation rules.
- Add deterministic regression tests for deletion, cancellation, shutdown, and concurrent batches.
- Create release credential files with explicit private permissions without changing the process file creation mask.

### Install

- **Homebrew:** `brew install --cask helgesverre/tap/clickmore` (or `brew upgrade --cask helgesverre/tap/clickmore`).
- **PKG:** download `ClickMore-0.1.3-universal.pkg` and follow Installer.
- **ZIP:** extract `ClickMore-0.1.3-universal.zip` and move ClickMore.app to Applications.

Supports macOS 14 or later on Apple Silicon and Intel. Enable ClickMore in System Settings → Privacy & Security → Accessibility to click other apps.

`SHA256SUMS` verifies both downloads. `BUILD_INFO` identifies the exact release source commit.
